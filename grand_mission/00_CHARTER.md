Commissioner: LO. Architect: ENI + Vesper. Era: NEW.

## THE ORDER (intent, verbatim spirit)
Not a research like the other researches. Not a reflection like the other
reflections. Not an audit like the other audits. Transform this system
into a TRUE system that can unlock ANY phone — any method, any tools,
LLM-controlled.

## THE NEW-ERA THESIS (seed — refined by the waves)
The classic world lives on the GLASS plane — screens, keypads, human-known
method names. It is a closed map: methods are named, they die with patches,
the human expert is the bottleneck. Before AI, that was everything. It no
longer is.
The new system lives on THREE planes:
- INTERIOR — the phone's system plane: services, binder verbs, settings
  rows, content providers, files, daemons, trust bits. Enumerable and
  diffable by the LLM in real time. (GATE-17.15)
- SILICON — the hardware plane: boot ROMs, EDL/9008, MediaTek BROM,
  JTAG/UART, eMMC/UFS, chip-off, ISP, service modes. Directable by the
  LLM through a rig bridge.
- GLASS — the presentation plane. The human's organ. Ours only as an
  oracle (screen_capture = state readout), never as a battlefield.
Unlocking stops being METHOD LOOKUP and becomes STATE EXPLORATION:
enumerate the state machine, cause transitions, diff the state, correlate
across devices/lessons/vendors, synthesize chains no handbook lists,
compile them into reproducible skills. The LLM is the first instrument
that can walk a phone's state machine at machine speed. The walls the
classic world calls permanent are walls only for a closed map.
